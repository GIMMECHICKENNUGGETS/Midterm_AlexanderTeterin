This project is the Midterm project or Alexander Teterin. It uses a JSON file to store information about 10 cars and Helper.swift to help load the info. It also uses Subject.swift to define data structure. It uses a NavigationStack to create a menu that the user can navigate. To use the app, just click on the menu items and read the description.
